# Báo cáo triển khai

Thư mục này hiện chỉ có hướng dẫn; chưa có test hoặc deployment nào được thực hiện cho ứng dụng mới.

Model triển khai tạo:
- environment.md: versions thực tế, project refs không secret.
- provider-check.md: model ID đã verify, quota và smoke.
- phase-P00.md ... phase-P13.md: lệnh, kết quả, ca manual.
- content-review.md: manifest, reviewed/draft counts.
- deployment.md: GitHub SHA, Vercel status, stable URL.
- release-v1.md: copy và điền từ templates/release-checklist.md.

Không ghi secret, auth cookie, access token, DB password hoặc API key.
